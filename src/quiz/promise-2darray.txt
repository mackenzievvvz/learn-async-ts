the output does looks different: summation occurs during the main event loop,
not at the end after the main program has ended.

this is because the event loop will typically complete microtasks/timers while completing IO
operations. Because we used setTimeout, the summation was in the timer queue. 
So while the main program's console.log() are being executed (IO operations),
the CPU has space to do the summation in the timer queue.
 
However, when setTimeout is removed from the Promise into another function,
the summation is put into microtasks/pending callbacks. So the microtask
is completed by the CPU first before going to the the primary IO operations
from the main program.
